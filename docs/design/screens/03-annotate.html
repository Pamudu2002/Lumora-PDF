Chapter 2

Why documents need versions

Notes from the reading list

A document is a promise that the words will stay put. A good editor records what happened and keeps it, so that anyone who opens the file later can see the same thing the author saw.

That promise is easy to break. Saving over a file replaces the old version, and a signature applied before an edit no longer matches the bytes on disk. An incremental save appends changes instead, which keeps earlier signatures valid.

Three rules for safe editing

First, treat every change as a step that can be reversed: undo works for every change, including page moves and form values. Second, never write over the original until the new file is complete. Third, keep a journal of unsaved changes so a crash costs nothing.

Annotations should be standard objects, not pictures painted onto the page. Any viewer can then show, hide, reply to or remove them, and the text underneath stays searchable.
