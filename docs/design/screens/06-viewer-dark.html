Lumora PDF — Product & Technical Plan

Version 1 · October 2026

Overview

Lumora PDF is a fast, private, offline-first PDF reader and editor by Lumora, built for everyday PDF work. It ships on Windows first, then Linux, macOS and iOS/iPadOS from one codebase.

Vision: everything people do with PDFs — read, annotate, organize, fill, sign, edit, OCR — in a small app that opens instantly, works without an account, and never sends documents to the cloud unless the user asks.

PDF engine and licensing

Lumora PDF uses PDFium for rendering, text, annotations and forms, plus qpdf or lopdf for structure work. Both allow closed-source commercial use and sit behind Lumora's own engine interface.

Tech stack

Lumora PDF is built with Tauri 2: a React and TypeScript interface on top of a Rust core that drives PDFium. One codebase covers Windows, Linux, macOS, iOS and Android, and the installed app stays small.

Every PDF operation flows through the engine adapter, and every edit is a command, so undo and redo work everywhere.
