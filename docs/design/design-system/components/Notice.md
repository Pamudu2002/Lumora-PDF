# Notice

An inline message bar under the toolbar or inside a panel or dialog.

- **Provide:** a tone, a sentence that says what happened and what to do, and optionally one action button (`lu-btn--sm`) and a dismiss button.
- **Tones:** info (`brand-soft`), success, warning, danger (their `-soft` backgrounds), and tip (`lumen-soft`, icon and lead phrase in `lumen-ink`) for helpful suggestions and What's new. Text stays `ink`; the icon carries the tone color.
- Use notices for document state ("This file has form fields"); use a dialog only when the person must decide now.
- Tips suggest, never sell: every feature is free, so a tip never mentions upgrades, plans or limits.
