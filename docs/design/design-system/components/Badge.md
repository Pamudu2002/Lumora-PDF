# Badge

One or two words of state beside a name: a file's status, a new feature, a signature result.

- **Provide:** the word(s) and a tone. Status tones carry an icon too, so meaning never rests on color.
- **Tones:** neutral (`surface-sunken`, `ink-muted`) · `--new` (`lumen` fill, `on-lumen` text — only for a feature added in the latest release, removed after one release) · `--brand` (informational) · `--success`, `--warning`, `--danger` on their `-soft` backgrounds.
- Sentence case, 11px `caption` weight 600. Never put badges on tool groups to restrict them: every Lumora PDF feature is free.
